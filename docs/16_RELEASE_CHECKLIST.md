# Demo Release Checklist

## Product
- [ ] North-star journey works end to end.
- [ ] Synthetic-data label is visible.
- [ ] Methodology and limitations are available.

## Data
- [ ] Seed process succeeds from a clean database.
- [ ] No client-derived data is present.
- [ ] Representative benchmark cases are included.

## AI
- [ ] Model and prompt versions are recorded.
- [ ] Output validation is enabled.
- [ ] Unknown evidence identifiers are rejected.
- [ ] Benchmark report is reviewed.

## Cost
- [ ] Pricing configuration has an effective date.
- [ ] Every LLM call records usage.
- [ ] Retry cost is included.
- [ ] Projections show assumptions.

## Engineering
- [ ] Format, lint, typing and tests pass.
- [ ] No secrets are committed.
- [ ] Setup instructions work in a clean environment.
- [ ] Known defects are documented.

## Demo
- [ ] Short, typical and complex records are preselected.
- [ ] Failure scenario is understood.
- [ ] Live LLM dependency and fallback approach are stated.
- [ ] Demo narrative focuses on evidence, exceptions and economics.
